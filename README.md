# 🟢 REVERSI (リバーシ)

洗練されたダークモダンUIと、思考AI・リアルな3Dアニメーションを搭載したシングルファイル完結型のリバーシ（Reversi）Webゲームです。  
PC・スマートフォンのどちらからでもブラウザを開くだけで快適に対局できます。

---

## 🌟 特徴 (Features)

- **3段階のAI対戦ルーチン (vs AI)**
  - **初級:** ランダムベース（時折角を優先する手加減AI）
  - **中級:** マス目の位置評価値＋獲得石数による盤面スコアリング
  - **上級:** 探索深度4のMinimax探索＋Alpha-Beta（アルファベータ）枝刈りによる本格派
- **2人対戦モード (Pass & Play)**: 1台の端末で交互に打てる対人戦モード
- **立体的な演出・フィードバック**
  - **3Dフリップアニメーション:** 石がひっくり返る立体的なCSS 3D演出
  - **リアルタイム形勢バー:** 盤面の黒白比率をバーゲージで可視化
  - **着手可能マスガイド:** 打てるマスを直感的にハイライト表示
  - **Web Audio API サウンド:** 外部音源不要のプログラマブルな効果音（着手・反転・パス・勝利ファンファーレ）
- **対局アシスト機能**
  - **待った（アンドゥ）:** AI戦では自分の直前の手まで2手セットでスマートに巻き戻し
  - **自動パス検出:** 打てる手がない場合の自動通知＆スキップ
  - **サウンドON/OFF切り替え**

---

## 🎮 遊び方 (How to Play)

1. **ゲーム開始:** 先手は「黒」、後手は「白」です。
2. **操作方法:**
   - ハイライト（緑色の点）が出ているマスをクリック／タップして石を置きます。
   - 挟んだ相手の石が自分の色にひっくり返ります。
3. **終局:** 盤面がすべて埋まるか、両者ともに打てる手がなくなると対局終了。石の多い方が勝利となります。

---

## 🛠 開発について (About Development)

このプロジェクトは、**生成AI（Gemini）を活用したバイブコーディング（対話型プログラミング）** によって開発されたシングルファイルWebアプリケーションです。

- **ディレクション / 仕様設計:** teratere
- **AIアシスタント (コード生成):** Gemini 3 Flash
- **構成技術:**
  - HTML5 / CSS3 (Tailwind CSS, CSS 3D Transforms)
  - Vanilla JavaScript (ES6+, Minimax Algorithm)
  - Phosphor Icons (UIアイコン)
  - Web Audio API (シンセサイズ効果音)
